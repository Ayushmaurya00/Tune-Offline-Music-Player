Technical Questions

FAQ

Where is library and playback data stored?

All database tables, playlist indices, and track configurations are persisted in local browser storage (IndexedDB) or local JSON application state within the user's OS AppData directory. Nothing is synchronized to any external server.

Does the 10-band equalizer introduce phase distortion?

No. The equalizer utilizes standard second-order biquadratic filter nodes provided natively by the Web Audio specification. With Q-factors clamped to 1.414, transitions between octave bands remain smooth without audible ringing or phase cancellation.

How does Tune handle album cover fetching?

Tune first extracts embedded APIC / ID3 picture frames directly from your audio files. If absent, you can trigger the Tag Editor's iTunes Lookup, which fetches artwork directly from Apple's public catalog without needing an account.

Is Tune free of telemetry and analytics?

Yes. There are zero analytics SDKs (no Google Analytics, no Sentry, no Mixpanel, no PostHog). The only network calls made by the application are direct fetches to lrclib.net (for lyrics) and itunes.apple.com (for tags), both of which can be completely avoided in offline mode.
